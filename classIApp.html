Detailed Description

Une application a boucle.

run() est ECRIT ici : c'est du code, pas une promesse de plus. On en herite pour remplir event / update / display, et rien d'autre.

Il n'y a pas d'init() ni de destroy() : ce sont le constructeur et le destructeur. Un objet qui existe est un objet pret. 

class MyApp : public IApp {
public:
    MyApp() { ... }              // init
    ~MyApp() override { ... }    // destroy
protected:
    void event() override   { ... }
    void update() override  { if (done) stop(); }
    void display() override { ... }
};
